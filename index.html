📥 Demandes reçues

    🚀 Publier avec GitHub + Vercel

    1. Cliquez sur Télécharger HTML pour obtenir votre fichier à jour.
    2. Créez un dépôt sur github.com, puis Add file → Upload files et nommez le fichier index.html.
    3. Sur vercel.com : New Project → importez le dépôt → Deploy.
    4. Votre carte est en ligne 🎉 Pour toute mise à jour, remplacez index.html dans le dépôt : Vercel actualise le site automatiquement.
